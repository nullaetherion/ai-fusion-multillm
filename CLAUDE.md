AI Fusion is a professional portfolio project: a Multi-LLM AI Assistant with OpenAI, Claude and Gemini support.

The project must be clean enough for:
- GitHub portfolio

## Working Rules

- Work incrementally.
- Implement only the requested task.
- Inspect only files relevant to the task.
- Do not refactor unrelated code.
- Do not add future features early.
- Use TypeScript strictly.
- Keep secrets in environment variables.

- Prefer simple production-quality code.
- Run relevant checks after changes.
